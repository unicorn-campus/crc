# 과제 수행 방법 안내
## 사전설치 
- 가이드: https://github.com/unicorn-plugins/npd/blob/main/resources/guides/setup/prepare.md
- AI툴 중 본인이 사용하는 툴만 설치(Claude Code, Codex, Cursor 등)

## 과제 
- ① 개인 과제
  - 교재 17페이지의 '상담 현장 질문'에 어떤 유형의 작업이 적절한 지 답변 
  - '생성'인 경우 '생성'이라고 답함
  - '예측'인 경우 '예측'이라고 답함
  - '검색'인 경우 '정형검색', '유사도검색', '관계검색'중 하나로 답함
  - 여러 작업이 필요한 경우 모든 작업을 적음. 예) 정형검색+생성
  - 결과는 '개인과제-{본인별명}.xlsx'로 작성(예: 개인과제-온달.xlsx) 
      
- ② 팀 과제: 논리아키텍처 설계
  - 이벤트 모델링 예제를 참고하여 본인 팀의 고객군에 맞는 논리 아키텍처 설계
  - 전체 관계도와 내부 구성도를 각각 작성
  - 결과는 '팀과제-{팀명}.pptx'로 작성(예: 팀과제-1조.pptx)

## 과제 제출 방법 
- 개인과제: [과제 제출 구글 드라이브](https://drive.google.com/drive/u/0/folders/1IFKcUr_IdXDHmJyI5rUJnHuWGHslu-2a)에 '개인과제-{본인별명}.xlsx' 파일로 업로드 
- 팀과제: [과제 제출 구글 드라이브](https://drive.google.com/drive/u/0/folders/1IFKcUr_IdXDHmJyI5rUJnHuWGHslu-2a)에 '팀과제-{팀명}.pptx' 파일로 업로드
